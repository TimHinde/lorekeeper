# System packs

Optional, system-specific material carried over from Tome. Nothing in the core
depends on these, and they have not yet been ported to the vault format.

| Pack | Contents | Status |
|---|---|---|
| `dnd5e-srd/` | SRD 5.2 PDF (CC BY 4.0) and Tome's reference search | Not ported. The SRD PDF doubles as a large test input for the PDF scripts. |
| `nimble/` | Nimble 2e rules notes and the 5e-to-Nimble conversion prompt | Not ported. |

A pack will eventually be a folder of vault-format entities (mostly `lore` and
`creature`) that can be merged into a vault, plus any system-specific skills.
